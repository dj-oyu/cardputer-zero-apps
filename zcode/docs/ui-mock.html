  • Ctrl+/ と Ctrl+` の / と ` は Sym レイヤーのキー（/ は Sym+N、` は Sym+W）。Ctrl と Sym を同時に押す操作になるので、押しやすさを実機で確かめて最終決定する。

未確定・要確認

  • Sym レイヤーの記号: キーボードドライバは Sym 中にテンキー系のキーコード（KP7、KPASTERISK など）を送る。 どの刻印がどの文字になるかは、実機でキーを押して確かめてから対応表を作る（キー確認モードを最初に実装する）。
  • 日本語入力は SKK を zcode に組み込む（uim は fb0 アプリに届かないため）。辞書は実機の /usr/share/skk/SKK-JISYO.L と個人辞書 ~/.skk-uim-jisyo（どちらも EUC-JP）を そのまま使い、uim-skk と学習結果を共有する。CJK は Noto Sans Mono CJK で描く。
  • 入力モードはステータスバー右端に出す: 緑「かな」/ 黄「カナ」/ 薄い「A」（英数）。起動時は英数。
  • 作業フォルダの既定は ~/code。
