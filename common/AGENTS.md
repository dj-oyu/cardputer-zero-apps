# common

液晶アプリ共通の UI 土台 `zero_ui.py`。API の一覧は `README.md` と
モジュール先頭の docstring。

## 触るときの注意

- 各アプリの `build.sh` がこのファイルを .deb へコピーするので、
  変更は **全アプリに効く**。変更したら各アプリの `--render-test` を
  回し、意図しない差分が出ないことを確認する（切り出し時は
  リファクタ前後で描画出力がバイト一致することを確かめた）
- 振る舞いを変える変更を入れたら、使っている各アプリのバージョンを
  上げて .deb を出し直す必要がある
- アプリ固有の処理はここに入れない。2 つ以上のアプリで使うものだけ
- 表示規約（結果は無編集表示、コピーは Enter の明示操作だけ）は
  `draw_panel()` に含まれている。崩さない
